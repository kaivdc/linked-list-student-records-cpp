# Linked List Implementation of a Student Records System
A C++ implementation of linked lists for a student records system with multiple data points. Another simple user-input loop that uses files for the saving/loading of information. This project was completed as an exam over 2 hours, showcasing:
 - Experience in Linked Lists
 - Understanding of Data Structures
 - Error-handling and edge case resolution skills
 - File functionality
Completed in Visual Studio Code, Simply runnable by downloading the executable and creating any required files via prompting within the console while code is running.
